# Physical collateral concepts

Generated September 12, 2026 with the built-in image_gen tool for the four active MixedRoutes logo application screens. These are photographic concept mockups, not photographs of manufactured products or production-ready artwork.

The four testing pages are labeled A, B, C, and D. Their original asset identifiers remain A, B, E, and F respectively, so the existing image and screen paths stay stable.

The reference images were browser exports of each existing application screen's logo stage. The E reference used the approved three-color treatment. Exact submitted prompts are in `prompts.json`; the original vector logo assets remain the source for production artwork.

All four PNGs are 1536 × 1024. They are displayed below the existing applications without cropping. Original generated files remain in the Codex generated-images directory.

Option A was edited with built-in image_gen to replace the heavy line-and-dot decoration on the tote and card with two slim parallel lilac routes. The original PNG is retained. The exact edit prompt is in `option-a-route-edit-prompt.txt`.

Option D (asset id B2) is not a new generation. It is the option B photograph with the old marks painted out and the B2 mark composited back in (cylinder warp on the mug and sleeve, tilted print on the postcard, lighting and grain matched). The postcard window uses `design-system/marketing-v2-assets/outdoors.jpg`.

The A and C cafe images are made the same way as B2, so all three unified screens share one scene: the option B photograph with its marks painted out and the A or C mark composited back in. C is shown one color on each object.
