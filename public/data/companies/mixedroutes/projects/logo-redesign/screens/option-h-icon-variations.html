Option H: MX cross
as an app icon

Eight takes on two crossing lines, from heavier strokes to blobby tapers. Each is shown at App Store, home screen, and settings sizes, plus on white.

H1Thick

The original, pushed to a heavier stroke and a wider stance so the crossing sits high.

H2Chunky

Fat capsules. Peaks nearly touch, so it reads as a bold M first.

H3Heavy feet

Each line swells toward the bottom, like a drop landing. Light up top, planted below.

H4Round peaks

Big round heads, slimmer legs. The two humps make the M louder.

H5Bowed legs

Legs stand up straight before leaning in, so the outer strokes act like the sides of an M.

H6Run off

Oversized so the legs run out the bottom of the icon. Just the crossing and the peaks.

H7Knockout

One color. The crossing is cut out, so it still reads as two lines at any size.

H8Melted

One color, heavy feet, and the crossing melted together so the joint swells like wet paint.
